# Task Manager Frontend

This is the Next.js frontend for the Task Management system.

## Setup
1. Ensure Node.js 18+ is installed.
2. Run `npm install`
3. Run `npm run dev`
4. Access at `http://localhost:3000`

## Testing
Run Jest unit/integration tests:
```bash
npm run test
```

Run Cypress E2E tests:
```bash
npm run cypress:run
```
